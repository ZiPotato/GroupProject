# OhjelmointitiimissaToimiminen opiskelijapohja

Tama repositorio on opiskelijoiden palautuspohja ohjelmointitiimissa toimiminen -kurssille.

Kurssin varsinainen teoria, taustamateriaalit ja tehtavien tarkemmat ohjeet loytyvat alkuperaisesta materiaalirepositoriosta:

- [PohjaOhjelmointitiimissaToimiminenEN (alkuperainen)](https://github.com/gradia-ohjelmistokehitys-kurssipohjat/PohjaOhjelmointitiimissaToimiminenEN)

## Aloita nain

1. Hyvaksy GitHub Classroom -tehtava ja kloonaa oma repositoriosi.
2. Avaa tama kansio editorissa tai Visual Studiossa.
3. Lue taman repositorion kansiot ja paikalliset README- tai markdown-ohjeet.
4. Avaa alkuperainen materiaalirepo, kun tarvitset kurssin varsinaiset ohjeet, teorian tai taustamateriaalit.
5. Tee oma tyosi tahan repositorioon.
6. Committaa ja pushaa tyosi saannollisesti.

Voit tehda kurssin joko valmiin harjoituspolun mukaan tai opettajan hyvaksymaan omaan projektiin perustuen.

## Suositeltu tyotapa

- tee tyo omassa repossasi, ei alkuperaisessa materiaalirepossa
- kayta feature branch -tyoskentelya ja pull requesteja kurssin ohjeiden mukaan
- pilko tyo user storyihin ja issueihin ennen toteutusta
- pida commitit pienina ja viestit selkeina
- varmista, etta koodi toimii ennen pushia

## Tärkeää

- tama repo toimii opiskelijatyon palautuspohjana
- varsinainen kurssisisalto yllapidetaan alkuperaisessa materiaalirepossa
- opiskelijoiden ei tarvitse lisata `upstream`-remotea tai synkata materiaaleja gitilla, ellei opettaja erikseen ohjeista niin
- ala committaa kansioita `bin/`, `obj/`, `.vs/` tai muita build-artefakteja

## Kurssimateriaalin lahde

Jos kurssin ohjeisiin tai materiaaleihin tarvitaan muutoksia, ne kannattaa tehda alkuperaiseen materiaalirepositorioon. Tama repo voidaan nimeta ja julkaista opiskelijapohjana erikseen.
